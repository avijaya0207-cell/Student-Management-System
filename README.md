Student Management System

A responsive Student Management System built using HTML, CSS, JavaScript, and Firebase.

Features

- Admin Login and Logout
- Add new student records
- View student records
- Edit student details
- Delete student records
- Search students by name, roll number, or department
- Firebase Firestore database integration
- Secure admin access using Firebase Authentication and Firestore Security Rules
- Responsive design for mobile and desktop

Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Cloud Firestore
- GitHub Pages

Live Demo

https://avijaya0207-cell.github.io/Student-Management-System/

Installation

1. Clone or download this repository.
2. Create a Firebase project.
3. Enable Email/Password Authentication.
4. Create a Cloud Firestore database.
5. Configure Firebase settings in "index.html".
6. Set Firestore Security Rules to allow only the authorized admin.
7. Open "index.html" in a browser or deploy using GitHub Pages.

Project Purpose

This project was developed as part of a Full Stack Development Internship to demonstrate frontend development, database integration, authentication, and CRUD operations.
